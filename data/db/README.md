# 인격·E.G.O 데이터 사본

사이트 저장 공간(db)의 인격·E.G.O를 깃허브에 옮겨 둔 **사본**이에요.

| 파일 | 내용 |
|---|---|
| `identities.json` | 인격 (db에 입력한 것. 기본 인격 12명(LCB)은 사이트 파일 안에 있어서 여기 없음) |
| `egos.json` | E.G.O (db에 입력한 것) |
| `export_db.py` | db에서 내려받은 문서 폴더로 위 두 파일을 다시 만드는 도구 |

- **원본은 사이트 db예요.** 사이트에 반영하려면 사이트 관리자 탭에서 고쳐요. 이 파일을 고쳐도 사이트는 바뀌지 않아요.
- 삭제한 인격·E.G.O는 빠져 있고, 수감자 순 → 출시일(E.G.O는 등급) 순으로 정렬돼 있어요.
- 데이터 구조는 `docs/HANDOFF.md` 5장, E.G.O는 `docs/EGO-변환-안내.md`를 봐요.
