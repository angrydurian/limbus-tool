# 키워드 아이콘 · 설명

편성 도구(`limbus-tool.html`)에 들어 있는 키워드 아이콘 394개와 설명을 따로 모은 폴더예요.

- `keywords.json`: 키워드 목록
  - `name`: 이름, `icon`: 그림 파일(`icons/`), `icon_variants`: 특정 인격용 다른 그림(예: 재장전 gray), `icon_all`: 그림이 여러 개인 키워드의 전체 그림
  - `aliases`: 같은 그림을 쓰는 다른 표기
  - `desc`: 효과 설명 (이탤릭 설명 문구는 뺌), `support`: 지원 인격·E.G.O·기프트, `note`: 기타
  - `category`: 나무위키 분류 — `기본`(화상·출혈·진동·파열·침잠·호흡·충전·참격·관통·타격) / `범용` / `고유`(v0.2 아이콘 순서에서 탄환부터)
  - `source`: 설명을 옮긴 캡처 파일(`source/`), `checked`: 사람이 캡처와 대조해 확인했으면 true
  - `rules`: 아이콘을 붙이지 않는 문구(예외), "관" 규칙, 그림 변형 조건
- `icons/`: 아이콘 PNG (배경 투명)
- `source/`: 나무위키 키워드 목록 캡처 원본

**주의**: 설명은 캡처를 OCR(글자 인식)로 옮긴 초안이에요. "%"가 "9"로 읽히거나 글자가 빠진 곳이 남아 있을 수 있어요. 툴팁(v0.3)에 쓰기 전에 `source/` 캡처와 대조해서 고치고 `checked`를 true로 바꿔요. 기존 아이콘 중 53개는 캡처가 없어서 설명이 비어 있어요.
