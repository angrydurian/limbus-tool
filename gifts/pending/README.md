# 기프트 남은 일 (2026-11-20 멈춘 곳)

다음 대화를 시작하면 사용자에게 아래 두 가지를 먼저 다시 알려 줄 것 (사용자 요청).

1. **영구동력 서보모터** (Ⅳ 충전, 워프특급 살인사건 팩, 구매불가 합성): 아이콘 캡처만 받았고 위키 글은 아직 못 받음.
   캡처는 이 폴더의 `영구동력 서보모터.png`. 글을 받으면 `parse_gifts.py`로 넣고 `add_icon.py`로 이 캡처를 잘라 붙인 뒤 이 파일과 캡처를 지운다.
2. **오타 확인**: "피로 된 살점, 살점으로 된 피" 효과의 "(펀성된 수 × 20)" → "편성"으로 고칠지 사용자 답 대기. 지금은 위키 그대로 "펀성".

현재 상태: 기프트 345개, 아이콘 345개 모두 있음, 조합식 재료 빠짐 없음.
