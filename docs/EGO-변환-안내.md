# 림버스 컴퍼니 E.G.O 캡처 → 편성 도구 붙여넣기용 JSON 변환 안내

이 문서는 E.G.O 캡처를 읽어서, 림버스 편성 도구(v3.0)의 **관리자 탭 → "E.G.O 데이터 붙여넣기"**에 그대로 넣을 JSON을 만드는 방법이에요.
> v0.5부터 '저장'은 사이트 저장 공간이 아니라 관리자 탭의 **'깃허브 반영 대기'**에 모여요. '변경분 복사'를 채팅에 붙여넣으면 깃허브 `data/db/egos.json`에 반영돼요.

아래 규칙을 지키면 붙여넣는 즉시 **검토 없이 바로 저장**돼요. 규칙에서 벗어나면 검토 양식이 열리거나, 값이 조용히 틀어져서 저장돼요.

---

## 1. 출력 규칙 (가장 중요)

- **E.G.O 하나당 JSON 하나**를 ```json 코드 블록 하나에 담아 출력한다. 설명 문장은 코드 블록 밖에 짧게만 쓴다.
- 여러 E.G.O를 한 번에 받으면, 코드 블록을 E.G.O 개수만큼 따로 출력한다. 한 블록에 배열로 묶지 않는다(도구는 한 번에 하나만 읽음).
- 맨 바깥 형식은 항상 이렇다:

```json
{"ego": { ...E.G.O 데이터... }, "uncertain": []}
```

- `id`는 넣지 않는다. 이미 등록된 E.G.O를 고치는 경우에만 바깥에 `"existingId":"e-..."`를 넣는다(사용자가 id를 알려줄 때만).
- 화면에서 읽을 수 없는 값만 `null`로 두고 그 키를 `uncertain`에 넣는다. **읽을 수 있는 값은 추측 없이 채우고 uncertain에 넣지 않는다.** uncertain이 하나라도 있으면 바로 저장되지 않고 검토로 넘어간다.
- 효과 문장은 화면 글자 그대로 옮긴다(띄어쓰기·괄호·기호 포함). 요약하거나 고쳐 쓰지 않는다.

## 2. 데이터 구조

```
{
  "sinner": "이상",                // 수감자 이름 (아래 12명 중 정확히 하나)
  "grade": "TETH",                 // ZAYIN | TETH | HE | WAW | ALEPH (대문자 그대로)
  "name": "E.G.O 이름",
  "base": false,                   // 수감자 고유 E.G.O면 true
  "cost": [["분노", 2], ["질투", 1]],  // 사용 비용: [죄악, 개수] 배열들
  "sanity": 10,                    // 정신력 소모 (0~100)
  "csanity": 15,                   // (v0.2) 침식 정신력 소모. 각성과 다를 때만 넣고, 같으면 빼거나 null. 고유 E.G.O는 null
  "lv": 66,                        // 공격 레벨 (1~120)
  "res": {"분노":"보통","색욕":"취약","나태":"보통","탐식":"보통","우울":"내성","오만":"보통","질투":"보통"},   // 취약 | 약점 | 보통 | 견딤 | 내성
  "awaken":    { 스킬 },           // 각성 스킬 (필수)
  "awaken2":   { 스킬 },           // 두 번째 각성 스킬 (있을 때만 넣음)
  "corrosion": { 스킬 } | null,    // 침식 스킬. 고유 E.G.O(base:true)면 null
  "corrosion2":{ 스킬 },           // 두 번째 침식 스킬 (있을 때만 넣음)
  "passive": {"name": "패시브 이름", "desc": ["문장", "문장"],
              "extra": [{"requires":[{"sinner":"이상","name":"인격 이름"}], "desc":["그 인격일 때만 보이는 문장"]}]},  // extra는 있을 때만 (v3.0)
  "t5": false,                     // 5해석 화면이 있으면 true
  "t5data": null                   // t5가 true면 5해석 값 (6번 참고)
}
```

### 스킬 형식 (awaken, awaken2, corrosion, corrosion2 공통)

```
{
  "name": "스킬 이름",
  "type": "참격",          // 참격 | 관통 | 타격 중 하나
  "sin": "분노",           // 스킬 죄악 속성
  "base": 4,               // 기본 위력 (0~99)
  "cp": 5,                 // 코인 위력 (-40~60, 음수면 음수 그대로)
  "coins": 2,              // 코인 개수 (1~10)
  "w": 1,                  // 공격 가중치 (1~10)
  "fx": ["번호 없는 효과 문장", "..."],
  "cf": [{"n": 1, "fx": ["Ⅰ번 코인 효과 문장"]}, {"n": 2, "fx": ["..."]}]
}
```

- 스킬에는 `lv`를 넣지 않는다. 공격 레벨은 E.G.O 전체에 하나(`lv`)만 있다. 각성·침식 레벨이 따로 보이면 **각성 스킬의 공격 레벨**을 `lv`에 넣는다.
- 인격 스킬에 있던 `slot`, `qty`, `bonus`, `by`, `requires`는 E.G.O에는 쓰지 않는다.

## 3. 값 규칙 (틀리면 오류가 나거나 조용히 바뀜)

| 키 | 허용 값 | 틀렸을 때 |
|---|---|---|
| `sinner` | 이상, 파우스트, 돈키호테, 료슈, 뫼르소, 홍루, 히스클리프, 이스마엘, 로쟈, 싱클레어, 오티스, 그레고르 | 오류 → 검토 |
| `grade` | `ZAYIN`, `TETH`, `HE`, `WAW`, `ALEPH` | 오류 → 검토 |
| 죄악 이름 (cost, sin, res 키) | 분노, 색욕, 나태, 탐식, 우울, 오만, 질투 | 오류 → 검토 |
| `cost` | `[["분노",2],["질투",1]]` 처럼 **배열의 배열**. 개수 1~20. 최소 1개 | `{"분노":2}` 같은 객체로 쓰면 비용이 비어 오류 |
| `res` 값 | **정확히** `"취약"`(×2), `"약점"`(×1.5), `"보통"`(×1), `"견딤"`(×0.75), `"내성"`(×0.5) 다섯 단어 중 하나. 화면 글자 그대로 쓰고 7죄악 모두 적기 (견딤 v2.8, 약점 v2.9부터) | ⚠ 다른 단어(예: "약점", "저항", "x1.5")를 쓰면 **오류 없이 "보통"으로 바뀌어 저장됨**. 다섯 단어 밖의 값이 보이면 `"res"`를 uncertain에 넣기 |
| 스킬 `type` | `"참격"`, `"관통"`, `"타격"` | 오류 → 검토. 화면이 셋 중 아니면 null + uncertain |
| 숫자들 | 숫자형(따옴표 없이). `"+5"` 말고 `5` | 범위 밖이면 오류 |
| `cf`의 `n` | 1부터, 그 스킬의 `coins` 이하 | 오류 → 검토 |

## 4. 캡처 읽는 법

- **코인 수(`coins`)** = 스킬 이름 위 점(코인) 개수.
- **코인별 효과**: 효과 앞의 로마 숫자(Ⅰ, Ⅱ, Ⅲ…)가 코인 번호 → `cf`에 `{"n": 번호, "fx": [...]}`. 같은 번호의 효과가 여러 줄이면 같은 `fx` 배열에 순서대로.
- **번호 없는 효과**(사용시, 합 승리시, 스킬 전체에 붙는 문장 등)는 `fx`.
- 가장 큰 코인 번호가 점 개수보다 크거나, 코인이 여러 개인데 효과가 앞쪽 코인에만 있어서 점 개수가 의심되면 `"A.coins"`처럼 그 스킬의 coins 키를 uncertain에 넣는다.
- **죄악 아이콘**: 분노=빨간 불꽃, 색욕=주황색 엮인 무늬, 나태=노란 돌덩이, 탐식=초록 잎, 우울=청록 소용돌이, 오만=파란 뾰족한 결정, 질투=보라색 가시 덩어리.
- **오버클록**(자원·정신력 1.5배)은 공통 규칙이라 넣지 않는다. 기본(오버클록 아닌) 비용과 정신력 소모를 넣는다.
- **정신력 소모가 각성·침식에서 다르게 보이면**(예: 저주못, 핏빛욕망) `sanity`에 각성 값, `csanity`에 침식 값을 넣는다(v0.2). 같으면 `csanity`는 넣지 않는다.

## 5. 고유 E.G.O, 두 번째 스킬

- 수감자 기본(고유) E.G.O는 `"base": true`, `"grade": "ZAYIN"`, `"corrosion": null`. 수감자당 고유 E.G.O는 하나뿐이다.
- 각성 스킬이나 침식 스킬이 두 개인 E.G.O만 `awaken2` / `corrosion2`를 넣는다. 없으면 키 자체를 빼거나 `null`.

---

### 패시브 편성 조건 효과 (`passive.extra`, v3.0)

- 패시브에 "[로보토미 E.G.O::엄숙한 애도 이상 전용 상시 효과]"처럼 **특정 인격 전용** 효과가 있으면, 그 부분은 `desc`가 아니라 `extra`에 넣는다.
- `extra`는 묶음 배열: `{"requires":[{"sinner":"이상","name":"로보토미 E.G.O::엄숙한 애도"}],"desc":[...]}`. `requires`의 인격이 모두 편성(대기 포함)에 있을 때만 화면에 보이고, 아니면 숨겨진다.
- 인격 이름은 도구에 저장된 이름(대괄호 없이)과 같게 쓴다. 띄어쓰기는 무시하고 비교한다.
- 전용 효과의 제목 줄("[… 전용 상시 효과]")도 `extra.desc`에 그대로 넣는다. 조건 없는 효과는 `desc`에 남긴다.
- 확인 필요 키는 `P.extra` (5해석은 `T.P.extra`).

## 6. 5해석 (`t5`, `t5data`)

- 기본은 **4해석** 화면 값이다. `awaken`, `corrosion`, `passive`에는 4해석 값을 넣는다.
- 5해석 화면 캡처도 받았으면 `"t5": true`, 그리고 `t5data`에 **5해석 값을 전부** 넣는다(달라지지 않은 부분도 포함, 같은 스킬 형식).

```json
"t5": true,
"t5data": {
  "awaken":    { 5해석 각성 스킬 전체 },
  "corrosion": { 5해석 침식 스킬 전체 },
  "passive":   {"name": "...", "desc": ["..."]}
}
```

- 4해석에 있는 스킬만 5해석에서도 읽힌다(4해석에 `awaken2`가 없으면 `t5data.awaken2`는 무시됨).
- 5해석이 있는 E.G.O인데 5해석 캡처가 없으면 `"t5": false`로 두고, 답변 밖에 "5해석 캡처가 없어 4해석만 넣었다"고 한 줄 적는다.

---

## 7. uncertain 키 이름 (이 이름만 쓰기)

다른 이름을 쓰면 검토 양식에서 노란 칸으로 표시되지 않는다.

- 기본: `sinner`, `grade`, `name`, `base`, `cost`, `sanity`, `csanity`, `lv`, `res`, `t5`
- 스킬: `A`(각성), `A2`(각성 2), `C`(침식), `C2`(침식 2) 뒤에 `.name` `.type` `.sin` `.base` `.cp` `.coins` `.w` `.fx` `.cf`
  예: `"A.coins"`, `"C.base"`, `"A2.cf"`
- 패시브: `P.name`, `P.desc`, `P.extra`
- 5해석: 앞에 `T.`를 붙인다. 예: `"T.A.base"`, `"T.C.cf"`, `"T.P.desc"`

## 8. 예시 (구조 참고용 — 값은 실제 E.G.O가 아님)

```json
{"ego":{
  "sinner":"이상","grade":"TETH","name":"예시 E.G.O","base":false,
  "cost":[["우울",2],["나태",1]],"sanity":10,"lv":66,
  "res":{"분노":"보통","색욕":"취약","나태":"보통","탐식":"보통","우울":"내성","오만":"보통","질투":"취약"},
  "awaken":{"name":"예시 각성","type":"관통","sin":"우울","base":5,"cp":3,"coins":2,"w":1,
    "fx":["[사용시] 예시 효과 문장"],
    "cf":[{"n":1,"fx":["[적중시] 예시 코인 효과"]},{"n":2,"fx":["[적중시] 예시 코인 효과"]}]},
  "corrosion":{"name":"예시 침식","type":"관통","sin":"우울","base":12,"cp":-4,"coins":3,"w":2,
    "fx":["피아식별불가"],
    "cf":[{"n":3,"fx":["[적중시] 예시 코인 효과"]}]},
  "passive":{"name":"예시 패시브","desc":["예시 패시브 문장"]},
  "t5":false,"t5data":null
},"uncertain":[]}
```

## 9. 출력 전 스스로 점검

- [ ] 코드 블록 하나에 `{"ego":{...},"uncertain":[...]}` 하나만 있다
- [ ] `sinner`·죄악 이름이 정해진 철자 그대로다
- [ ] `grade`가 대문자 다섯 개 중 하나다
- [ ] `cost`가 `[["죄악",개수],...]` 배열이다
- [ ] `res`에 7죄악이 모두 있고, 값은 `취약`/`약점`/`보통`/`견딤`/`내성` 중 하나다
- [ ] 모든 스킬에 `name`, `type`(참격/관통/타격), `sin`, `base`, `cp`, `coins`, `w`가 숫자·문자로 채워져 있다
- [ ] `cf`의 번호가 `coins` 이하다
- [ ] 고유 E.G.O면 `base:true`, `grade:"ZAYIN"`, `corrosion:null`
- [ ] 읽을 수 있는 값은 uncertain에 넣지 않았다

---

### (사람용 메모) 붙여넣은 뒤

- 바로 저장되면 관리자 탭에 "검토할 칸이 없어서 바로 저장했어요"가 나온다.
- 검토로 넘어가면 "검토가 필요해요: …" 메시지에 이유가 나온다(확인 필요 칸, 입력 오류, 같은 이름 중복, 기존 E.G.O 수정).
- 같은 수감자에게 같은 이름의 E.G.O가 이미 있으면 중복을 막기 위해 항상 검토로 간다.
